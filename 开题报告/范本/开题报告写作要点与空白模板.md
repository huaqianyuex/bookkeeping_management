## 二、逐项要点清单

### ① 整体结构顺序（固定，不可调换）

1. 封面 → 2. 表头信息 → 3. 设计背景 → 4. 文献调研 → 5. 主要设计目的 → 6. 设计内容 → 7. 拟采取的设计方法 → 8. 参考资料 → 9. 指导教师意见 → 10. 学院意见。
2. 逻辑主线是漏斗式：为什么做（背景）→ 别人做到哪（文献）→ 我要达成什么（目的）→ 具体做什么（内容）→ 怎么做（方法）→ 依据什么（文献列表）。
3. "设计内容"回答 What，"拟采取的设计方法"回答 How——两段严禁互相复述；方法是流程步骤（调研/设计/搭建/调试/测试），内容是系统组成（模块/算法/功能）。
4. 全文写在同一张大表格里，每栏以"栏目名："开头接长段文字，不另设 Word 标题样式层级。

### ② 每个章节写什么、写到什么程度

**设计背景（约 280~400 字，1 段）**
- 三步走：宏观趋势（"随着…的快速发展"）→ 领域价值与应用场景 → 现状痛点（"传统…多依靠…，无法满足…"）→ 落到本课题（"设计一款…，实现…功能，对…具有积极作用"）。
- 末句必须点题，出现与题目一致的关键词组。

**文献调研（约 900~1100 字）**
- 开头一句总起：概括该方向研究热度、常见平台、主流算法、典型应用场景。
- 分"一、国内研究现状 / 二、国外研究现状"，各 4~5 条；每条采用"序号 + 短语小标题 + 逗号展开说明"格式（如"1.传感器与执行机构，循迹多用…，避障多用…"）。
- 国内外条目维度要一一呼应（系统设计/传感器/通信/控制算法/平台工具），形成对照。
- 结尾"综上，国内外研究为本课题提供了…"：收束到本课题的技术路线可行性 + 尚存优化空间（为选题合法性背书）。
- 只归纳"别人做了什么、用什么方法"，不写文献评价长句，不逐篇罗列论文名。

**主要设计目的（约 350~450 字）**
- 第一段：一句话总述（"本课题旨在设计并实现一款…系统，通过…，实现…功能，构建…平台"）。
- 第二段："设计的主要目的体现在以下几个方面：一是…。二是…。三是…。"三条左右，分别从性能/体验/扩展性（或教学价值）角度写。
- 收尾："总体而言，本设计不仅能够…，还能为…提供…，具有…"。

**设计内容（约 1000~1300 字，最长一节）**
- 必须覆盖五个层面，且每个层面一个自然或以"系统总体设计：/硬件设计：/软件设计：/系统测试与优化："引导：
  - 总体：分层架构思想，列出全部硬件模块与软件模块清单；
  - 硬件：逐模块给出**具体型号/器件**（51 单片机、HC-05、L298N、OLED、红外反射阵列、超声波）及其作用；
  - 软件：开发环境 + 语言（Keil / C）、主程序-子程序结构、核心算法策略（差速控制、阈值判断、指令解析）；
  - 测试：列测试维度（单模块/通信/集成/长时间）与优化对象（阈值、参数、延时）。
- 末尾必须配图："系统总体设计图如图1所示：" + "图 1 系统总体设计图"。

**拟采取的设计方法（约 500~600 字）**
- 固定 5 步、编号"1.~5."：文献调研 → 系统设计 → 硬件选型与搭建 → 软件开发与调试 → 系统测试与评估。
- 每条写法：方法名 + 做什么 + 用什么工具/手段 + 达到什么效果（如"通过万用表与示波器进行信号检测与调试"）。
- 每条 80~120 字，不展开成段落级论述。

**参考资料（10~15 条）**
- 中英文混排，范文比例约 8 中文 + 7 英文。
- 时效性：以近 3 年为主（范文全部落在 2021~2024）。
- 相关性：题目关键词高度贴合（单片机/智能小车/STM32/送药小车/快递箱…）。
- 中文期刊格式：`[n]作者(3人以上加"等").题名[J].刊名,年,卷(期):起-止页.`
- 英文期刊直接按 `作者.题名[J].刊名,年,卷(期):页.` 著录。
- 正文（文献调研）引用时以上标 `[1]` 形式按出现顺序编号。

### ③ 格式细节（来自 PDF 批注，学校通用排版口径）

**字体字号**
- 一级标题：黑体，小三号；二/三/四级标题：黑体四号→小四号；标题与序号之间空一格（如"1 绪论"）。
- 正文：小四号宋体，两端对齐，段前段后 0，行距固定值 26 磅。
- 中英文混杂：中文宋体时英文用 Times New Roman；中文黑体时英文用 Arial。
- 特定名词/外文缩写首次出现须括号注明全称：如 URL（Uniform Resource Locator）、OECD（Organization for Economic Co-operation and Development）。

**图、表、公式**
- 插图前空一行，图名后空一行；表格表头前空一行、表后空一行。
- 表格、图题、单位、表头：小四号宋体加粗；图名在图下、表名在表上，按"章.序号"编号（图 2.3、表 2.2）。
- 表格优先三线表：头尾线 1 磅、中间线 0.75 磅。
- 跨页续表重复表头，表号后加"(续)"置于表上方：如"表 2.2 (续)"。
- 公式另起一行居中，行首无缩进；编号用英文圆括号置于右边行末，公式与编号间不加虚线；引用多次的公式不得另编号。公式所在行取消 26 磅固定行距，避免显示不全。
- 另起一页一律用分页符，禁止用空格或回车顶页。

**页眉页码**
- 页眉小五号宋体，顶端距离 15mm，内容为"学校名+本科毕业论文（设计）"。
- 正文页码用阿拉伯数字重新起算；前置部分（摘要/目录）用罗马数字。
- 全文时间数字用半角阿拉伯数字。

**参考文献表**
- 标题另起一页，小三号黑体，空一行后列条目。
- 中文条目五号宋体；英文条目五号 Times New Roman；`[1][2]` 编号字号可能需单独设置。

**时间表述（全文通用）**
- 写"2014年6月"，不写"14年6月"或"2014.6"；写"上世纪80年代/20世纪80年代"，不写"80年代"；时刻写"下午3点10分"，表格里才可写"3:10PM"。

### ④ 语言风格与常见句式

风格基调：客观说明文，主语用"本课题 / 本文 / 本设计 / 该系统"，不用"我"；不做无依据的夸张评价；动词偏好"实现、构建、采用、引入、提升、保证、验证"。

可迁移句式库：
- 背景起笔：随着……的快速发展，……逐渐成为……的重要方向。／ ……在带来……的同时也衍生出了……
- 痛点转折：传统……多依靠……，……低、……单一，无法满足……需求。
- 点题收束：设计一款基于……的……，实现……、……及……等功能，对……具有积极作用／较高的实用与教学意义。
- 文献总起：近年来基于……研究逐步增多，相关工作围绕……展开，平台以……较为常见，算法以……为主，应用于……等场景。
- 条目展开：序号+短语小标题，随后"多用…／常见…／部分研究引入…／少量工作尝试…"（注意"多—部分—少量"的梯度措辞，避免绝对化）。
- 文献收束：综上，国内外研究为本课题提供了成熟的……，结合……特点，采用……可实现……的平衡，后续在……仍有优化空间。
- 目的陈述：本课题旨在设计并实现一款……，通过……，实现……，构建……平台。／ 设计的主要目的体现在以下几个方面：一是…。二是…。三是…。
- 内容陈述：系统由……模块、……模块与……模块组成。／ ……选用……，用于……，实现……功能。／ 软件部分以……为主要开发语言，基于……平台进行模块化编程。
- 方法陈述：通过查阅……，了解……，为本设计提供理论依据与技术参考。／ 采用……思想／策略，根据……，确保……。
- 测试陈述：从……、……及……四个方面进行系统测试。／ 通过记录与分析测试数据，对……进行优化，确保系统在……下依旧稳定可靠运行。
