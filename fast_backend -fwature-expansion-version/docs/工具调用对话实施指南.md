# 工具调用对话（Agent 化）实施指南

> 目标：把 AI 对话从「静态注入当月财务块」升级为「模型按需调用只读查询工具」，让「上月餐饮花了多少」「最近三个月哪个月超支」「我上次买打印纸是什么时候」这类跨月 / 检索类问题可以被正确回答。
>
> 编写日期：2026-09-28。基于当前代码逐文件核对后编写，所有路径相对 `fast_backend/`。
> 姊妹文档：`docs/语音记账实施指南.md`（结构对齐：修正假设 → 里程碑 → 逐文件改动 → 验收 → 风险）。

## 0. 范围与不做的事

**做**：对话链路 Agent 化（bind_tools + 流式工具循环）；新增 5 个只读查询工具；SSE 契约向后兼容；降级与开关；pytest 用脚本化假模型覆盖循环逻辑；论文对照实验 V2 的设计。

**不做（明确出界）**：
- **不在对话工具里提供任何写操作**。写仍走 `/ai/bookkeeping`（幂等 + 审计链），两条链职责分离：bookkeeping 链管「精确写」，对话工具只管「灵活读」。
- **不持久化工具中间消息**。`messages` 表 role 契约是 user/assistant（`models/chat.py:60`），落库仍只有用户消息 + 最终助手文本。
- **不改前端也能用**。M1+M2 上线后 SSE 事件仍是 `content|done|error`，两端零改动；M3/M4（status 提示、图表）是可选增强。

## 2. 架构与不变量

```
用户消息
  │  routers/ai.py（装配不变：SYSTEM_PROMPT + finance_block + history + human）
  ▼
ai/chat_flow.py::stream_chat_with_tools(db, user_id, messages)
  │  每请求: tools = ai/tools.py::build_tools(db, user_id)   ← 闭包注入身份
  │  循环（≤ AI_TOOL_MAX_ROUNDS 轮）:
  │    bound = llm.bind_tools(tools)         # 末轮强制去工具，逼出最终回答
  │    astream → 实时 yield {"type":"content","content":…}（SSE 契约不变）
  │    轮末读 buf.tool_calls：
  │      无 → 结束
  │      有 → yield {"type":"status", …}(M3 可选) → 执行工具(≤3s 超时)
  │              → messages += [AIMessage(tool_calls), ToolMessage(结果)] → 下一轮
  ▼
路由层把 content 拼成 full，落库 assistant 消息，发 done —— 与现状完全一致
```

**不变量（违反即回归）**：
1. SSE 三事件 `content|done|error` 语义、字段名、顺序不变；新增事件只允许是「可被旧解析器忽略」的类型。
2. 工具层**只读**；所有查询以闭包里的 user_id 过滤，`Record.status == 1` 口径不破。
3. 工具执行异常不外抛成 SSE error——转成 ToolMessage 里的中文错误文本，让模型如实回答（对齐 FAQ 降级哲学：数据不可用 ≠ 服务不可用）。
4. 裸返回契约（`{"error": …}` HTTP 200）不变。

```python
async def search_records_by_keyword(
    db: AsyncSession,
    user_id: int,
    keyword: str,
    limit: int = 10,
    month: str | None = None,
):
    """按备注关键词搜索本人未软删记录（AI 工具层专用，v1 不开 HTTP 端点）。

    - LIKE 元字符经 escape_like 转义（utils/security.py 同源，防 %/_ 注入）；
    - month 为 yyyy-MM，与 get_records_by_user 相同的半开区间处理；
    - limit 硬上限 50，防止被当作免费全表导出。
    返回 [(Record, Category | None), ...] 按 date 倒序。
    """
    conditions = [
        Record.user_id == user_id,
        Record.status == 1,
        Record.remark.like(f"%{escape_like(keyword)}%", escape="\\"),
    ]
    if month is not None:
        year, m = month.split("-")
        start = date(int(year), int(m), 1)
        end = date(int(year) + 1, 1, 1) if int(m) == 12 else date(int(year), int(m) + 1, 1)
        conditions.append(Record.date >= start)
        conditions.append(Record.date < end)

    result = await db.execute(
        select(Record, Category)
        .outerjoin(Category, Record.category_id == Category.id)
        .where(*conditions)
        .order_by(Record.date.desc(), Record.id.desc())
        .limit(min(limit, 50))
    )
    return result.all()
```

### 4.3 新建 `ai/tools.py`（全码）

```python
"""对话查询工具层 — 把 crud 只读查询包装成 LLM 可调用工具（Agent 化 M1）

设计口径：
- 身份走闭包：build_tools(db, user_id) 每请求构建工具对象，db/user_id 不进
  模型可见的参数 schema —— 模型在结构上无法越权查他人数据；
- 只读：v1 不提供任何写工具，写操作仍走 /ai/bookkeeping（幂等 + 审计链）；
- 月参统一 yyyy-MM（模型负责把「上个月」换算成具体月份，它从 finance_block
  的「今天是 …」行得知今天）；解析失败返回中文提示让模型自行纠正，不抛异常；
- 结果有上限：条数 ≤ AI_TOOL_MAX_RECORDS、备注截 40 字、金额 float(Decimal)，
  输出紧凑 JSON 字符串（ToolMessage 内容按 token 计费，越短越省）。
"""
import json
import re
from datetime import date, timedelta
from typing import Annotated

from langchain_core.tools import tool
from sqlalchemy.ext.asyncio import AsyncSession

from config.settings import AI_TOOL_MAX_RECORDS
from crud.record import get_records_by_user, search_records_by_keyword
from crud.statistics import get_category_stats, get_summary

_MONTH_RE = re.compile(r"^(\d{4})-(\d{1,2})$")
_TYPE_NAME = {0: "支出", 1: "收入"}


def parse_month(month: str | None, today: date) -> tuple[int, int] | None:
    """'2026-8'/'2026-08' → (2026, 8)；空/'latest' → 当月；非法 → None"""
    if not month or not month.strip() or month.strip().lower() in ("latest", "now", "当月", "本月"):
        return today.year, today.month
    m = _MONTH_RE.match(month.strip())
    if not m:
        return None
    year, mon = int(m.group(1)), int(m.group(2))
    return (year, mon) if 1 <= mon <= 12 else None


def _clip_records(rows, cap: int, remark_len: int = 40) -> list[dict]:
    out = []
    for record, category in rows[:cap]:
        out.append({
            "date": record.date.isoformat(),
            "type": _TYPE_NAME.get(record.type, "?"),
            "amount": float(record.amount),
            "category": category.name if category else None,
            "remark": (record.remark or "")[:remark_len] or None,
        })
    return out


def build_tools(db: AsyncSession, user_id: int) -> list:
    """按请求构建工具列表（闭包绑定 db/user_id；today 同 context.py 口径取服务器本地日期）"""
    today = date.today()

    @tool
    async def query_month_summary(
        month: Annotated[str, "要查询的月份，yyyy-MM 格式，如 2026-08"],
    ) -> str:
        """查询某个自然月的总收入、总支出与结余。回答任何涉及具体月份收支的问题前必须先调用本工具，禁止凭记忆估算。"""
        ym = parse_month(month, today)
        if ym is None:
            return "参数错误：month 需为 yyyy-MM，如 2026-08"
        income, expense = await get_summary(db, user_id, ym[0], ym[1])
        return json.dumps({
            "month": f"{ym[0]}-{ym[1]:02d}",
            "income": float(income),
            "expense": float(expense),
            "balance": float(income - expense),
        }, ensure_ascii=False)

    @tool
    async def query_category_stats(
        month: Annotated[str, "要查询的月份，yyyy-MM 格式"],
        type: Annotated[int, "0=支出(默认) 1=收入"] = 0,
    ) -> str:
        """查询某月各分类的金额合计，按金额降序。用于「钱都花在哪了」「分类构成」类问题。"""
        ym = parse_month(month, today)
        if ym is None:
            return "参数错误：month 需为 yyyy-MM"
        if type not in (0, 1):
            return "参数错误：type 只能是 0(支出) 或 1(收入)"
        rows = await get_category_stats(db, user_id, ym[0], ym[1], stat_type=type)
        return json.dumps({
            "month": f"{ym[0]}-{ym[1]:02d}", "type": _TYPE_NAME[type],
            "items": [{"category": name, "amount": float(amt)} for _, name, amt in rows[:12]],
        }, ensure_ascii=False)

    @tool
    async def query_records(
        month: Annotated[str | None, "限定月份 yyyy-MM；不传则查全部"] = None,
        category_name: Annotated[str | None, "分类名，需与用户分类精确同名"] = None,
        type: Annotated[int | None, "0=支出 1=收入；不传则不限"] = None,
        limit: Annotated[int, "返回条数，默认 10"] = 10,
    ) -> str:
        """按月份/分类/类型翻查账单明细（按日期倒序）。用于「本月大额支出有哪些」类问题；关键词搜索请改用 search_records。"""
        ym = parse_month(month, today) if month else ("skip", "skip")
        if month and ym is None:
            return "参数错误：month 需为 yyyy-MM"
        result = await get_records_by_user(
            db, user_id, page=1, size=min(max(limit, 1), AI_TOOL_MAX_RECORDS),
            type_=type if type in (0, 1) else None,
            month=None if not month else f"{ym[0]:04d}-{ym[1]:02d}",
        )
        # category_name 过滤在 Python 层做（工具层避免再写一个 crud 变体）
        if category_name:
            result["rows"] = [
                (r, c) for (r, c) in result["rows"]
                if c and c.name == category_name.strip()
            ]
        return json.dumps({"total": result["total"], "items": _clip_records(result["rows"], AI_TOOL_MAX_RECORDS)},
                          ensure_ascii=False)

    @tool
    async def search_records(
        keyword: Annotated[str, "关键词，匹配账单备注"],
        month: Annotated[str | None, "可选，限定月份 yyyy-MM"] = None,
        limit: Annotated[int, "返回条数，默认 10"] = 10,
    ) -> str:
        """按关键词搜索账单备注。用于「我上次买 X 是什么时候 / 花了多少」「有没有买过 X」类问题。"""
        kw = (keyword or "").strip()
        if not kw:
            return "参数错误：keyword 不能为空"
        ym = parse_month(month, today) if month else None
        if month and ym is None:
            return "参数错误：month 需为 yyyy-MM"
        rows = await search_records_by_keyword(
            db, user_id, kw,
            limit=min(max(limit, 1), AI_TOOL_MAX_RECORDS),
            month=f"{ym[0]:04d}-{ym[1]:02d}" if month else None,
        )
        return json.dumps({"keyword": kw, "count": len(rows),
                           "items": _clip_records(rows, AI_TOOL_MAX_RECORDS)}, ensure_ascii=False)

    @tool
    async def query_expense_trend(
        months: Annotated[int, "回看月数，2~12，默认 6"] = 6,
    ) -> str:
        """查询最近 N 个月（含当月）每月的总收入与总支出。用于「最近几个月哪个月花得多」「趋势」类问题；一次调用即返回，不要按月重复调用 query_month_summary。"""
        n = min(max(months, 2), 12)
        items = []
        y, m = today.year, today.month
        for _ in range(n):
            income, expense = await get_summary(db, user_id, y, m)
            items.append({"month": f"{y:04d}-{m:02d}", "income": float(income), "expense": float(expense)})
            m -= 1
            if m == 0:
                y, m = y - 1, 12
        items.reverse()
        return json.dumps({"items": items}, ensure_ascii=False)

    return [query_month_summary, query_category_stats, query_records,
            search_records, query_expense_trend]
```

**实现注意**：
- `query_records` 里 `category_name` 的 Python 层过滤只作用于当页 20 条，total 不变——这是已知不精确点，docstring 已引导模型优先用 `search_records`/`query_category_stats`；如答辩被问到，如实说明并列为后续项（SQL 层 JOIN 过滤）。
- 全部工具返回 `str`（`@tool` 要求）；异常不在此层捕获，统一由 M2 的 `_run_tool` 兜底。

## 5. M2 对话流程改造（2 投入日）

### 5.1 新建 `ai/chat_flow.py`（全码）

```python
"""对话主流程 — 带工具调用的流式循环（Agent 化 M2）

契约：
- 对外只 yield {"type":"content","content":…}（v1），SSE 三事件语义不变；
  M3 起可能 yield {"type":"status","text":…}，旧前端天然忽略；
- 工具中间消息（AIMessage(tool_calls)/ToolMessage）只在本次请求的内存
  messages 里流转，不落库；
- 硬失败（重试后仍异常）向上抛，路由按现有口径转 SSE error / ai_error。

降级路径（三层）：
1. AI_TOOLS_ENABLED=false → 纯 astream，与 v1.0.0 行为一致；
2. 工具轮流式调用抛异常且本轮无任何产出 → 记日志、去掉工具重试一次；
3. 单个工具执行失败/超时 → ToolMessage 返回中文错误，模型如实回答。
"""
import asyncio
import json
import logging
from typing import AsyncIterator

from langchain_core.messages import AIMessage, AIMessageChunk, BaseMessage, ToolMessage

from ai.tools import build_tools
from config.settings import AI_TOOL_MAX_ROUNDS, AI_TOOL_TIMEOUT_SECONDS, AI_TOOLS_ENABLED

logger = logging.getLogger(__name__)


async def _run_tool(tools_by_name: dict, tc: dict) -> str:
    """执行单个工具调用；任何失败都转成模型可读的中文错误文本（不外抛）"""
    name = tc.get("name") or ""
    impl = tools_by_name.get(name)
    if impl is None:
        return f"错误：不存在名为 {name} 的工具，请改用现有工具或如实回答"
    try:
        result = await asyncio.wait_for(
            impl.ainvoke(tc.get("args") or {}), timeout=AI_TOOL_TIMEOUT_SECONDS
        )
        return result if isinstance(result, str) else json.dumps(result, ensure_ascii=False)
    except asyncio.TimeoutError:
        logger.warning("tool %s timeout", name)
        return "错误：查询超时。请告知用户数据暂时查不到，不要编造数字"
    except Exception as exc:
        logger.warning("tool %s failed: %s", name, exc)
        return "错误：查询执行失败。请如实告知用户暂时查不到该数据"


async def stream_chat_with_tools(
    db, user_id: int, messages: list[BaseMessage]
) -> AsyncIterator[dict]:
    """流式产出事件；messages 会被原地追加工具轮消息（调用方无需复用它）"""
    llm = get_chat_llm()  # ← from ai.llm import，测试时 monkeypatch 本模块引用
    tools = build_tools(db, user_id) if AI_TOOLS_ENABLED else None
    tools_by_name = {t.name: t for t in tools} if tools else {}

    rounds = 0
    while True:
        bound = llm.bind_tools(tools) if (tools and rounds < AI_TOOL_MAX_ROUNDS) else llm
        buf: AIMessageChunk | None = None
        try:
            async for chunk in bound.astream(messages):
                buf = chunk if buf is None else buf + chunk
                if chunk.content:
                    yield {"type": "content", "content": chunk.content}
        except Exception:
            # 三层降级之 2：仅当本轮毫无产出（大概率网关不支持 tools）时去工具重试
            if rounds == 0 and tools is not None and (buf is None or not buf.content):
                logger.warning("tool-call stream failed, retry without tools", exc_info=True)
                async for chunk in llm.astream(messages):
                    if chunk.content:
                        yield {"type": "content", "content": chunk.content}
                return
            raise

        # 轮末解析工具调用；args JSON 未闭合等解析失败按「无工具」处理（记日志）
        tool_calls = []
        if buf is not None:
            try:
                tool_calls = list(getattr(buf, "tool_calls", None) or [])
            except Exception:
                logger.warning("tool_calls parse failed", exc_info=True)

        if not tool_calls or rounds >= AI_TOOL_MAX_ROUNDS:
            return

        rounds += 1
        yield {"type": "status", "text": f"正在查询账单（第 {rounds} 次工具调用）"}  # M3 前端忽略之
        messages.append(AIMessage(content=buf.content or "", tool_calls=tool_calls))
        for tc in tool_calls:
            result = await _run_tool(tools_by_name, tc)
            messages.append(ToolMessage(content=result, tool_call_id=tc["id"]))


async def chat_with_tools(db, user_id: int, messages: list[BaseMessage]) -> str:
    """非流式口径：收齐全部 content 返回完整文本（/chat 用）"""
    parts = []
    async for ev in stream_chat_with_tools(db, user_id, messages):
        if ev["type"] == "content":
            parts.append(ev["content"])
    return "".join(parts)
```

顶部补 `from ai.llm import get_chat_llm`（示例中为标注测试注入点而写在引用处注释）。

**实现注意**：
- `AIMessageChunk + AIMessageChunk` 会按 index 合并 `tool_call_chunks`，轮末 `.tool_calls` 即完整解析结果——这是 langchain-core 0.3 的稳定用法，不手拼 JSON 片段。
- 末轮（`rounds == AI_TOOL_MAX_ROUNDS`）绑定空工具强制模型给最终回答，杜绝工具死循环。
- 工具轮可能先流出少量引导语（「让我查一下…」）再发 tool_calls，导致最终气泡里出现两段文字。缓解：SYSTEM_PROMPT 已约束「调用工具的轮次不要输出正文」；残余风险见 §10-3，M4 的图表协议会顺带改善展示。

from langchain_core.messages import AIMessageChunk


class ScriptedStreamModel:

def tool_chunk(name: str, args: str, call_id: str = "call_1") -> AIMessageChunk:
    return AIMessageChunk(content="", tool_call_chunks=[
        {"name": name, "args": args, "id": call_id, "index": 0, "type": "tool_call_chunk"}

### 8.2 `tests/test_chat_flow.py` — 四个必过用例

1. **零工具轮**：脚本一轮 `[AIMessageChunk(content="你好")]` → 事件只有 content，`bind_called` 可为 False（或 True 后无 tool_calls 即止）。
2. **一工具轮**：先出 `tool_chunk("query_month_summary", '{"month": "2026-08"}')` 再出 `[AIMessageChunk(content="上月支出…")]`；monkeypatch `chat_flow.build_tools` 返回带假实现的工具列表（记录收到的 args）；断言：第二轮 `seen_messages` 里出现 `AIMessage(tool_calls=…)` 与 `ToolMessage(content=假结果, tool_call_id="call_1")`。
3. **超轮次上限**：AI_TOOL_MAX_ROUNDS=1（monkeypatch settings），脚本连续两轮都出 tool_chunk → 第二轮 `bind_called` 路径强制去工具（可用两个假模型序列断言末轮 messages 追加了两对工具消息后终止）。
4. **工具抛异常**：假工具 raise → 循环不崩，ToolMessage 内容含「错误」，最终正常产出回答。

另补 `tests/test_tools_unit.py`：`parse_month`（含 "2026-8"、非法、当月兜底）与 `_clip_records`（截断、None remark）纯函数断言——不需要 DB。
