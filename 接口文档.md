## 一、用户模块 `/api/user`

### 1.1 用户注册

- 请求方式：POST
- 路径：`/api/user/register`
- 是否需要登录：否

请求体：

| 字段     | 类型   | 必填 | 说明                     |
| -------- | ------ | ---- | ------------------------ |
| username | String | 是   | 用户名，2-20位，不能重复 |
| password | String | 是   | 密码，6-20位             |

请求示例：
```json
{
    "username": "zhangsan",
    "password": "123456"
}
```

成功响应参数（data）：

| 字段     | 类型   | 说明   |
| -------- | ------ | ------ |
| id       | Long   | 用户ID |
| username | String | 用户名 |

成功响应示例：
```json
{
    "code": 200,
    "message": "注册成功",
    "data": {
        "id": 1,
        "username": "zhangsan"
    }
}
```

失败场景：

| 场景         | code | message        | 类型   |
| ------------ | ---- | -------------- | ------ |
| 用户名已存在 | 500  | 用户名已存在   | String |
| 用户名为空   | 400  | 用户名不能为空 | String |
| 密码为空     | 400  | 密码不能为空   | String |

## 三、账单记录模块 `/api/records`

### 3.1 分页查询账单

- 请求方式：GET
- 路径：`/api/records`
- 是否需要登录：是
- 请求头：`Authorization: Bearer {token}`

请求参数：

| 字段       | 类型    | 必填 | 说明                       |
| ---------- | ------- | ---- | -------------------------- |
| page       | Integer | 否   | 页码，默认1                |
| size       | Integer | 否   | 每页条数，默认10           |
| categoryId | Long    | 否   | 按分类筛选                 |
| month      | String  | 否   | 按月份筛选，格式 "2026-05" |

成功响应参数（data）：Object（分页结构）

| 字段    | 类型              | 说明           |
| ------- | ----------------- | -------------- |
| records | Array\<RecordVO\> | 当前页数据列表 |
| total   | Long              | 总记录数       |
| pages   | Long              | 总页数         |
| current | Long              | 当前页码       |
| size    | Long              | 每页条数       |

RecordVO 结构：

| 字段         | 类型          | 说明                            |
| ------------ | ------------- | ------------------------------- |
| id           | Long          | 记录ID                          |
| userId       | Long          | 用户ID                          |
| categoryId   | Long          | 分类ID                          |
| categoryName | String        | 分类名称（来自 category 表）    |
| categoryType | Integer       | 0支出/1收入（来自 category 表） |
| amount       | BigDecimal    | 金额                            |
| remark       | String        | 备注，可能为 null               |
| recordDate   | LocalDate     | 记录日期，格式 yyyy-MM-dd       |
| createTime   | LocalDateTime | 创建时间                        |
| updateTime   | LocalDateTime | 更新时间                        |

成功响应示例：
```json
{
    "code": 200,
    "message": "操作成功",
    "data": {
        "records": [
            {
                "id": 1,
                "userId": 1,
                "categoryId": 1,
                "categoryName": "餐饮",
                "categoryType": 0,
                "amount": 35.50,
                "remark": "午饭",
                "recordDate": "2026-05-12",
                "createTime": "2026-05-12T12:00:00",
                "updateTime": "2026-05-12T12:00:00"
            }
        ],
        "total": 50,
        "pages": 5,
        "current": 1,
        "size": 10
    }
}
```

## 六、数据库参考

```sql
-- 用户表
CREATE TABLE user (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(100) NOT NULL,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 分类表
CREATE TABLE category (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL,
    type TINYINT NOT NULL COMMENT '0支出 1收入',
    user_id BIGINT NOT NULL,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 账单记录表
CREATE TABLE record (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    category_id BIGINT NOT NULL,
    amount DECIMAL(10,2) NOT NULL,
    remark VARCHAR(200),
    record_date DATE NOT NULL,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

## 八、DTO 与 VO 说明

```
DTO（Data Transfer Object）：前端 → 后端
  RegisterDTO：注册参数
  LoginDTO：登录参数
  CategoryDTO：分类新增/修改参数
  RecordDTO：账单新增/修改参数
  PasswordDTO：修改密码参数

VO（View Object）：后端 → 前端
  UserVO：用户信息（不含密码）
  RecordVO：账单信息（含分类名称）
  MonthlyStatisticsVO：月度统计
  CategoryStatisticsVO：分类统计
```
