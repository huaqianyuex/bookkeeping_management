# 简记 · 微信小程序端接入与适配手册

> 适用项目：`personal-ledger-uniapp`（uni-app + Vue3 + Vite）
> 面向对象：开发 / 部署工程师
> 结论先行：本项目**可以在微信端直接编译**，但**需要完成若干配置与适配后才能「真正可用、可上传、可发布」**。本手册按「必改 / 建议 / 可选」三级标注清单 + 接入步骤 + 常见问题排查展开。

| 维度 | 现状 | 是否可直接用 |

## 1. 必改项（不做则微信端跑不起 / 发不了）

### 1.1 后端接口地址（src/api/config.js:26）

当前非 H5 分支写死局域网 IP：

```js
// #ifndef H5
_BASE_URL = 'http://192.168.101.84:8000/api'   // ← 开发期需改成你电脑局域网 IP
// #endif
```

接入微信端必须注意：

- **开发者工具**：不能用 `127.0.0.1`/`localhost`（指向工具自身，不是你的电脑）。改为电脑局域网 IP（`ipconfig` 查 IPv4）。
- **真机调试**：手机与电脑同一 WiFi，且电脑 IP 需保持稳定（建议在路由器为电脑绑定静态 IP，或改用域名）。
- **上线发布**：必须换成**线上 HTTPS 备案域名**（见 1.3），此处 IP 不能用于生产。
- 建议：把 `_BASE_URL` 改为**可配置/按环境区分**（开发、测试、生产各一份），避免发布时手动改代码。

### 1.2 填写微信 AppID（src/manifest.json:80）

```json
"mp-weixin": {
  "appid": "",   // ← 填入你的小程序 AppID
  "setting": {
    "urlCheck": false
  },
  "usingComponents": true
}
```

- 到 [微信公众平台](https://mp.weixin.qq.com) 注册「小程序」获取 AppID。
- 未填 AppID 只能以「测试号」导入，**很多能力（合法域名、上传、真机预览）受限**。
- 填入后需重跑 `npm run build:mp-weixin` 重新编译，并在开发者工具里重新导入。

### 1.3 配置合法请求域名（生产必须）

微信对网络请求有硬性限制，`urlCheck:false` **只关掉了开发工具的校验**：

- 在微信公众平台 →「开发管理」→「开发设置」→「服务器域名」添加：
  - `request 合法域名`：你的后端接口域名（生产 HTTPS）
  - `uploadFile 合法域名`：头像上传接口域名（`src/api/user.js:19` 用 `uni.uploadFile`）
  - `downloadFile 合法域名`：若前端下载/展示远程图片/文件（注意：`<image>` 加载远程图不强制在此列，但 uploadFile 域名必须配）
- **域名要求**：必须 `HTTPS`、已备案、不能带路径和端口。
- **开发期**：可通过开发者工具「详情 → 本地设置 → 勾选『不校验合法域名』」临时绕过，仅本地调试用。

## 2. 建议适配项（提升稳定性 / 体验）

### 2.1 AI 流式输出（SSE）真机兼容性

`src/api/ai.js` 非 H5 分支用 `uni.request({ enableChunked:true })` + `onChunkReceived` 解析。实测建议：

- 微信开发者工具表现正常；
- **真机 iOS 一直是主要用户**，长对话下注意内存与分包限制；
- 建议在切换微信基础库版本（工具「详情 → 本地设置 → 调试基础库」）验证 `enableChunked`。
- 若个别机型收不到 chunk，可给 AI 接口加**降级轮询**兜底（后端已有会话列表/历史接口，可轮询最新消息）。

### 2.2 自定义导航栏与安全区

多数页面 `navigationStyle: "custom"`，微信端顶部有**状态栏 + 胶囊按钮（右上角）**：

- 当前 `getStatusBarHeight()` + `uni.getSystemInfoSync()` 已拿到状态栏高度（`src/pages/user/index.vue:120`）。
- 需确认自定义头部的 `top` 是否避开了胶囊按钮（胶囊 top ≈ 状态栏高度 + 4rpx、胶囊高 32px）。若需统一处理，可在通用组件（如 `TabBar.vue`、页面 `Header`）里读取并应用右上角胶囊安全区。

### 2.3 微信原生登录（可选功能扩展）

现状登录是 **用户名/邮箱 + 6 位 PIN** + JWT（配合后端 `fast_backend`）。若想「微信一键登录」：

- 前端调用 `uni.login({ provider: 'weixin' })` 获取 `code`；
- 后端需新增 `code2session` + `openid` 处理，映射到本地账号（首次可自动建号）；
- 这一步属于**功能性升级**，不是「跑起来」的必备项，可后置。

## 3. 可选优化（发行前）

- **分包**：主包上限 2MB。若后续图片/组件变大，将非首屏页面（如 `pages/ai-history`、`pages/password`）放入独立分包。
- **图标/字体**：检查有无本地内置大图片/字体文件增加包体积，可转线上资源。
- **头像上传**：微信 `uni.chooseImage` 返回 `tempFilePath`，若需压缩可在 `doUploadAvatar` 前用 `uni.compressImage` 进一步控制体积。
- **统计接口**：`manifest.json` 里 `uniStatistics.enable:false`，如需要可开启并配置所属应用。

## 4. 接入操作速查（CLI 方式，不依赖 HBuilderX）

项目用 Vite 命令行编译微信端：

```bash
cd personal-ledger-uniapp
npm install

# 开发预览（生成 dist/dev/mp-weixin，用开发者工具打开该目录）
npm run dev:mp-weixin

# 正式打包（生成 dist/build/mp-weixin）
npm run build:mp-weixin
```

导入步骤：

1. 打开**微信开发者工具** → 导入项目；
2. 目录选择 `personal-ledger-uniapp/dist/dev/mp-weixin`（dev）或 `dist/build/mp-weixin`（build）；
3. 填写 AppID（未填选测试号）；
4. 若连不上本机后端：勾选「详情 → 本地设置 → 不校验合法域名」；
5. 预览/上传。

## 5. 常见问题与排查

| 现象 | 原因 | 处理 |
|------|------|------|
| 请求一直 `fail ERR_CONNECTION_REFUSED` | `_BASE_URL` 用了 `127.0.0.1` 或写错 IP | 改电脑局域网 IP，手机同一 WiFi |
| `url 不合法` / 不能打开 | 域名未在合法域名内 | 后台配域名，或开发工具临时关校验 |
| 上传失败 `fail:domain` | `uploadFile` 域名未配置 | 后台加 uploadFile 域名 |
| 头像显示为空白/样式乱 | 自定义导航栏头部高度不含胶囊按钮 | 处理右上角胶囊安全区 |
| 登录/改密后反复跳登录页 | 6 位 PIN 号+JWT 校验失败或刷新 token 逻辑 | 检查后端 JWT 过期策略，沿用 H5 同样逻辑 |
| 真机无 AI 流式回复 | `enableChunked` 兼容页 | 换基础库/降级轮询 |
