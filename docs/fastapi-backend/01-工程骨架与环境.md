
> 版本建议按上表锁定；如 Python 版本受限，可放宽次版本（保持主版本一致），例如 `fastapi>=0.115,<1`。
> Python 建议 **3.11+**（3.12 亦可，aiomysql 已兼容）。

### BCrypt 依赖选型说明（D6，务必阅读）

Spring 的 `BCryptPasswordEncoder`（强度 10）产出前缀为 `$2a$` 的哈希。Python 侧**推荐直接用 `bcrypt` 库**而非 `passlib`：

- `passlib==1.7.4` 与 `bcrypt>=4.1` 存在兼容 bug（引用已删除的 `bcrypt.__about__.__version__`），会产生警告甚至报错；
- `bcrypt.checkpw` 本身支持校验 `$2a$`/`$2b$` 前缀的哈希，且 **bcrypt 4.x 对 72 字节以上密码默认抛错**，与 Spring 的静默截断行为不同——对 6 位数字密码无影响（本系统注册/改密均限制 `^\d{6}$`），但实现时统一前置校验长度即可规避。

兼容层代码见 `03-通用组件.md` §3；存量 hash 实测步骤见 `08-迁移手册.md`。

### 4.3 `app/core/config.py` 参考骨架（用户可扩展）

```python
from functools import lru_cache
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", env_file_encoding="utf-8", extra="ignore")

    # 服务
    app_host: str = "0.0.0.0"
    app_port: int = 8080
    cors_origins: str = "http://localhost:5173,http://localhost:3000"

    # MySQL
    mysql_host: str = "localhost"
    mysql_port: int = 3306
    mysql_user: str = "root"
    mysql_password: str = "change-me"
    mysql_db: str = "bookkeeping_book"
    mysql_charset: str = "utf8mb4"

    # 上传
    avatar_dir: str = "uploads/avatars"
    avatar_url_prefix: str = "/uploads/avatars/"
    max_avatar_size: int = 2 * 1024 * 1024

    # JWT
    jwt_secret: str = "***REMOVED***"
    jwt_expire_seconds: int = 86400

    # AI
    agnes_api_key: str = ""
    openai_base_url: str = "https://apihub.agnes-ai.com/v1"
    chat_model: str = "agnes-2.5-flash"
    analyze_model: str = "agnes-2.0-flash"
    embedding_model: str = "text-embedding-3-small"

    # 对话记忆
    max_history_tokens: int = 2000
    keep_recent_messages: int = 6

    # FAQ
    faq_top_k: int = 3
    faq_similarity_threshold: float = 0.5

    # 清理
    purge_interval_hours: int = 6
    purge_delay_days: int = 7

    @property
    def mysql_dsn(self) -> str:
        return (
            f"mysql+aiomysql://{self.mysql_user}:{self.mysql_password}"
            f"@{self.mysql_host}:{self.mysql_port}/{self.mysql_db}?charset={self.mysql_charset}"
        )


@lru_cache
def get_settings() -> Settings:
    return Settings()
```

> 注意：pydantic-settings 环境变量**大小写不敏感**地匹配字段名（`MYSQL_HOST` ↔ `mysql_host`），与上表一致。

## 5. 启动方式

### 5.1 Windows 本地开发（对应「项目启动文档」Step2）

```powershell
cd backend/fastapi-backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

> 若 PowerShell 禁止执行脚本：`Set-ExecutionPolicy -Scope Process RemoteSigned` 或改用

## 6. 实现红线提醒（贯穿全文）

1. **全异步**：凡可能阻塞的事件（DB、LLM HTTP 流、文件 IO 大对象）一律用 `async def` + `await`。
2. **前端零改动**：路由路径、HTTP 方法、JSON 字段名不许自行「优化改名」；改动请先看 00 §2.4。
3. 静态目录 `uploads/avatars` 建议从 `.env` 配置并保证进程有写权限。
