## 1. 统一响应 Result / PageResult

### 1.1 响应模型（`app/core/response.py`）

> 推荐实现方式：业务端点直接**返回 dict**，键用 camelCase（Java VO 本就如此），规避 Pydantic alias 的额外心智负担，也便于与旧响应逐字段 diff。模型类仅用于约束与文档。

```python
from typing import Any, Generic, Optional, TypeVar

T = TypeVar("T")


def ok(data: Any = None, message: str = "操作成功") -> dict:
    """业务成功响应：{"code":200,"message":...,"data":...}"""
    return {"code": 200, "message": message, "data": data}


def fail(code: int = 500, message: str = "操作失败", data: Any = None) -> dict:
    return {"code": code, "message": message, "data": data}
```

### 1.2 PageResult 构造（`records`/`admin` 业务列表使用）

```python
def page_result(records: list, total: int, page: int, size: int) -> dict:
    """与 Java PageResult{records,total,pages,current,size} 一致"""
    return {
        "records": records,
        "total": total,
        "pages": (total + size - 1) // size if size > 0 else 0,
        "current": page,
        "size": size,
    }
```

> ⚠️ **勿混淆两种分页**：业务用 `{records,total,pages,current,size}`；AI 会话列表用 `{items,total}`（见 05）。

## 2. 异常与状态码（`app/core/exceptions.py`）

Java 语义：

- 业务失败：`RuntimeException(message)` → HTTP 500 + body `{code:500,message,data:null}`
- 参数校验：`@Valid` 失败 → HTTP 400 + body `{code:400,message:首个字段中文message,data:null}`
- 未登录/token 失效：拦截器直写 → HTTP 401 + `{code:401,...}`
- 非管理员：→ HTTP 403 + `{code:403,message:"无管理员权限",data:null}`

### 2.1 自定义异常

```python
from fastapi import FastAPI, Request, status
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse


class BizError(Exception):
    """业务异常。status_code 决定 HTTP 状态，code/message 进 body。"""

    def __init__(self, message: str, code: int = 500, status_code: int = 500):
        self.code = code
        self.status_code = status_code
        self.message = message
        super().__init__(message)


def register_exception_handlers(app: FastAPI) -> None:
    @app.exception_handler(BizError)
    async def biz_handler(request: Request, exc: BizError):
        return JSONResponse(status_code=exc.status_code,
                            content={"code": exc.code, "message": exc.message, "data": None})

    @app.exception_handler(RequestValidationError)
    async def validation_handler(request: Request, exc: RequestValidationError):
        # Java Bean Validation 只回传首个字段错误；此处同样取首个错误最外层 message
        try:
            first = exc.errors()[0]
            loc = ".".join(str(x) for x in first.get("loc", []) if x != "body")
            msg = first.get("msg", "参数错误")
        except Exception:
            loc, msg = "", "参数错误"
        text = f"{msg}（字段：{loc}）" if loc else msg
        return JSONResponse(status_code=400,
                            content={"code": 400, "message": text, "data": None})

    @app.exception_handler(status.HTTP_401_UNAUTHORIZED)
    async def on_401(request: Request, exc):  # FastAPI HTTPException(401)
        return JSONResponse(status_code=401,
                            content={"code": 401, "message": "未登录", "data": None})

    @app.exception_handler(status.HTTP_403_FORBIDDEN)
    async def on_403(request: Request, exc):
        return JSONResponse(status_code=403,
                            content={"code": 403, "message": "无管理员权限", "data": None})

    @app.exception_handler(Exception)
    async def on_500(request: Request, exc: Exception):
        # 兜底：避免把堆栈暴露给前端
        return JSONResponse(status_code=500,
                            content={"code": 500, "message": "服务器内部错误", "data": None})
```

> 使用惯例：业务端点内校验失败用 `raise BizError("密码需为6位数字", code=400, status_code=400)`（400）；业务规则失败用 `raise BizError("用户名已存在")`（默认 500）。HTTP 401/403 由鉴权依赖抛出 `HTTPException` 即可被上面 handler 捕获。

## 3. 认证与密码（`app/core/security.py`）

### 3.1 JWT（与 Java `JwtUtil` 完全兼容：HS256、同一 secret、sub=userId 字符串、24h）

```python
import time
import jwt

from .config import get_settings

ALG = "HS256"


def create_token(user_id: int) -> str:
    s = get_settings()
    now = int(time.time())
    payload = {
        "sub": str(user_id),          # Java: subject = String.valueOf(userId)
        "iat": now,
        "exp": now + s.jwt_expire_seconds,
    }
    return jwt.encode(payload, s.jwt_secret, algorithm=ALG)


def parse_token(token: str) -> int:
    """校验并返回 user_id；失败抛 BizError(401)。"""
    from .exceptions import BizError
    s = get_settings()
    try:
        payload = jwt.decode(token, s.jwt_secret, algorithms=[ALG])
        return int(payload["sub"])
    except Exception:
        raise BizError("token无效或已过期", code=401, status_code=401)
```

> ⚠️ 兼容性说明（历史）：迁移期 `jwt_secret` 曾要求与 Java 后端旧密钥保持一致，旧 token 在过期前可无缝使用（D5 / 08）；该旧密钥现已作废并从仓库历史清除，新部署务必使用独立的随机强密钥。

### 3.2 BCrypt 兼容层（不用 passlib，直接用 bcrypt）

```python
import bcrypt

# Spring BCryptPasswordEncoder 强度 10 → 生成 $2a$10$...；bcrypt 库生成 $2b$。
# bcrypt.checkpw 对 $2a$ / $2b$ 前缀均可验证。→ 可直接校验存量 Spring 哈希。
_BCRYPT_ROUNDS = 10


def hash_password(plain: str) -> str:
    if len(plain.encode("utf-8")) > 72:
        raise BizError("密码过长", code=400, status_code=400)
    return bcrypt.hashpw(plain.encode("utf-8"), bcrypt.gensalt(rounds=_BCRYPT_ROUNDS)).decode("utf-8")


def verify_password(plain: str, hashed: str) -> bool:
    """验证明文与存量哈希；支持 Spring 的 $2a$ 前缀。"""
    try:
        return bcrypt.checkpw(plain.encode("utf-8"), hashed.encode("utf-8"))
    except ValueError:
        # 哈希格式异常时按不匹配处理，勿把异常抛给前端
        return False
```

> 理由（D6）：`passlib 1.7.4` 在 `bcrypt>=4.1` 下触发 `__about__` 兼容 bug；直接用 `bcrypt` API 最稳。系统密码规则 `^\d{6}$`，不涉及 72 字节边界。

## 4. 请求上下文与鉴权依赖（`app/api/deps.py`）

Java 用 `UserContext` ThreadLocal + 两个拦截器。FastAPI 异步场景改用**依赖注入**（线程池不保证同一线程，禁止 ThreadLocal）：

```python
from dataclasses import dataclass
from typing import Annotated, Optional

from fastapi import Depends, Header, HTTPException
from sqlalchemy.ext.asyncio import AsyncSession

from ..core.security import parse_token
from ..db.mysql import get_db_session   # 见 01 规划，02/04 会使用
from ..models.user import User


@dataclass
class CurrentUser:
    id: int
    role: int
    username: str


def _bearer(authorization: Optional[str] = Header(default=None)) -> str:
    if not authorization or not authorization.startswith("Bearer "):
        raise HTTPException(status_code=401)
    return authorization[len("Bearer "):]


async def get_current_user(
    token: str = Depends(_bearer),
    db: AsyncSession = Depends(get_db_session),
) -> CurrentUser:
    user_id = parse_token(token)                 # 失败 → BizError(401)
    # SELECT id, username, role FROM user WHERE id = :uid
    user = await db.get(User, user_id)
    if user is None:
        raise BizError("用户不存在", code=401, status_code=401)
    return CurrentUser(id=user.id, role=user.role or 0, username=user.username)


async def get_current_admin(user: CurrentUser = Depends(get_current_user)) -> CurrentUser:
    if user.role != 1:
        raise HTTPException(status_code=403)
    return user


# 类型别名，简化端点签名
CurrentUserDep = Annotated[CurrentUser, Depends(get_current_user)]
AdminDep = Annotated[CurrentUser, Depends(get_current_admin)]
```

路由挂载策略（对应 Java WebConfig 的 `addPathPatterns("/api/**")` 排除 login/register）：

- 需要登录的 `APIRouter` 统一加 `dependencies=[Depends(get_current_user)]`（如 `/api/categories`、`/api/records`、`/api/statistics`、`/api/user` 的除 register/login 外全部、`/api/ai/**`）。
- `/api/admin/**` 的 router 加 `dependencies=[Depends(get_current_admin)]`（注意管理接口仍要过登录校验——Java 是两拦截器叠加，故 admin 依赖内再依赖 current_user）。
- `POST /api/user/register`、`POST /api/user/login` 放在**无鉴权**的公开路由上。
- 从依赖里取用户：端点参数里声明 `user: CurrentUserDep`，不要全局变量。

## 5. 头像上传校验与保存（`app/api/utils/upload.py`）

依据 `UserServicesImpl.validateAvatar` / `updateAvatar` 的行为：

```python
import re
import uuid
from pathlib import Path

from fastapi import UploadFile

from ..core.config import get_settings
from ..core.exceptions import BizError

_ALLOWED_CONTENT_TYPES = {"image/jpeg", "image/png"}
_ALLOWED_EXTS = {".jpg", ".jpeg", ".png"}
_UUID_RE = re.compile(r"^[0-9a-f]{32}$")


def validate_avatar(file: UploadFile) -> None:
    s = get_settings()
    if file is None or not file.filename:
        raise BizError("请上传头像文件", code=400, status_code=400)

    # 长度检测需要读内容：由调用方先 read，再按字节数判断（见 save_avatar）
    ctype = (file.content_type or "").lower()
    if ctype not in _ALLOWED_CONTENT_TYPES:
        raise BizError("头像仅支持JPG/PNG格式", code=400, status_code=400)

    name = (file.filename or "").lower()
    if not any(name.endswith(e) for e in _ALLOWED_EXTS):
        raise BizError("头像仅支持JPG/PNG格式", code=400, status_code=400)


async def save_avatar(file: UploadFile) -> str:
    """校验 + 落盘，返回相对 URL（avatar_url）。"""
    s = get_settings()
    validate_avatar(file)
    data = await file.read()
    if len(data) > s.max_avatar_size:
        raise BizError("头像大小不能超过2MB", code=400, status_code=400)

    name = (file.filename or "").lower()
    ext = Path(name).suffix
    if ext not in _ALLOWED_EXTS:
        raise BizError("头像仅支持JPG/PNG格式", code=400, status_code=400)

    filename = uuid.uuid4().hex + ext          # Java: UUID.randomUUID() 去横线
    root = Path(s.avatar_dir).resolve()
    root.mkdir(parents=True, exist_ok=True)
    target = (root / filename).resolve()
    if not target.is_relative_to(root):
        raise BizError("非法文件路径", code=400, status_code=400)

    # 2MB 小文件同步写可接受；如需极致异步可用 anyio.to_thread.run_sync
    target.write_bytes(data)
    return f"{s.avatar_url_prefix}{filename}"
```

> 旧头像删除逻辑（`deleteOldAvatarIfExists`）：仅删除以 `AVATAR_URL_PREFIX` 开头的旧文件，防止误删。更新头像端点中实现时参考 04 §1.5。注意不要删掉外部 URL。

## 6. 挂载与主程序要点（`app/main.py`）

```python
from contextlib import asynccontextmanager

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from fastapi.staticfiles import StaticFiles

from app.core.config import get_settings
from app.core.exceptions import register_exception_handlers


@asynccontextmanager
async def lifespan(app: FastAPI):
    # 1. 确保 DB 连接池可用（可做 SELECT 1 探活）
    # 2. 初始化 FAQ 检索器（加载/生成向量，06）
    # 3. 启动 APScheduler 清理任务（07，单 worker 下才启动）
    yield
    # 关闭 DB engine 等


def create_app() -> FastAPI:
    s = get_settings()
    app = FastAPI(title="智能个人记账管理系统 FastAPI 后端", lifespan=lifespan)
    register_exception_handlers(app)

    origins = [o.strip() for o in s.cors_origins.split(",") if o.strip()]
    app.add_middleware(
        CORSMiddleware,
        allow_origins=origins,
        allow_credentials=True,
        allow_methods=["GET", "POST", "PUT", "DELETE", "OPTIONS", "PATCH"],
        allow_headers=["*"],
        expose_headers=["Authorization", "Content-Type"],
        max_age=3600,
    )
    # 静态头像（对应 WebConfig.addResourceHandlers）
    app.mount("/uploads/avatars", StaticFiles(directory=s.avatar_dir), name="avatars")
    # 注册路由：公开(user) / 业务 / admin / ai 见 04/05
    return app


app = create_app()
```

CORS 与 Java `WebConfig` 行为对照：`allowedOriginPatterns("*")` + `allowCredentials(true)` → 上面对应的是**显式 origin 列表**；如需完全放开可改 `allow_origin_regex=".*"`（安全性取舍，本地演示可放开，见 07）。

## 7. 序列化约定（供 04 照做）

| Java 类型 | FastAPI/Python | JSON 示例 |
|---|---|---|
| `LocalDateTime` | `datetime` 直接放 dict（FastAPI 自动 ISO8601） | `"2026-09-08T10:00:00"` |
| `LocalDate` | `date` | `"2026-09-08"` |
| `BigDecimal` | `Decimal` | `1234.56` |
| `Long` | `int` | `1` |
| 毫秒时间戳（chat 表） | `int` | `1725700000000` |

> 禁止输出 `datetime` 的带毫秒形式（若 DB `DATETIME` 含小数秒会输出 `.123456`）；建议 DDL 用 `DATETIME`（无小数），如需强约束可在序列化时 `str(dt).split(".")[0]`。
